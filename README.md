# LearnHub - Comprehensive Learning Platform

A modern, full-featured learning management system built with Next.js, React, and TypeScript.

## ✨ Features

### Core Features
- 🎓 Multiple courses with structured modules and lessons
- 📱 Responsive design (works on desktop, tablet, mobile)
- 👤 User authentication and profiles
- 📊 Progress tracking and analytics
- 🎯 Quiz system with scoring
- 🔥 Learning streak system
- 🏆 Achievement badges and milestones

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Icons**: React Icons

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/kolajoenoch-eng/Learning-hub.git
cd Learning-hub

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 Pages

- **Home** (`/`) - Hero section with featured courses
- **Courses** (`/courses`) - Browse all courses with filters
- **Login** (`/login`) - User authentication
- **Register** (`/register`) - Create new account
- **Dashboard** (`/dashboard`) - User progress and learning path
